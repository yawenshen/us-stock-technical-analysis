# US Stock Technical Analysis Skill

面向 Aime / AI Agent 的美股技术分析 Skill，融合 **Wave+Value 五因子模型**与 **Johnny 多周期关键位方法**，用于生成盘中趋势确认、收盘复盘、支撑压力、交易方向和风险计划。

> 本项目提供技术分析流程与风险管理框架，不构成投资建议，也不保证收益。所有关键位必须根据最新有效行情重新计算。

## 核心能力

- 使用 Wave+Value 五因子评估历史价格结构、均线趋势、量价筹码、Fibonacci 与 ATR
- 输出核心交易区、观察带和独立收盘失效线
- 判断左侧、右侧或观望策略，并给出确认条件
- 筛选每侧 2–3 个 Johnny 关键支撑位与压力位
- 支持主 Fib、局部导航 Fib、嵌套锚点 Fib 与次级扩展共振
- 结合 EMA8/13/21、EMA144/169 Vegas、TD 九转和基准指数
- 针对高波动标的启用趋势模式和防守性措辞
- 给出入场、止损、目标、仓位和收益风险比
- 支持多种可靠行情获取方式，并在单一通道失败时安全切换与校验

## 分析模式

### 融合模式（默认）

适用于：

- 美股盘中趋势确认
- 收盘复盘
- 短线支撑压力分析
- 左侧 / 右侧交易倾向
- 半导体及高波动标的风险计划

流程上先由 Wave+Value 五因子判断趋势和参考区域，再用 Johnny 多周期结构筛选关键位、校验确认条件与收益风险比。

### 纯 Johnny 模式

当请求中明确出现以下表达时启用：

- `Johnny分析策略`
- `Johnny策略`
- `用Johnny分析`
- `Johnny博主`

纯 Johnny 模式不强制使用 Wave+Value 权重、ATR 三层区间或左侧 / 右侧标签，而是输出离散的 `S1–S3`、`R1–R3`、市场状态、三套交易计划、持仓方案与风险预算。

## Wave+Value 五因子

| 因子 | 权重 |
| --- | ---: |
| 历史价格结构 | 35% |
| 均线趋势 | 20% |
| 成交量 / 筹码结构 | 20% |
| ATR 波动调整 | 10% |
| Fibonacci 回撤与扩展 | 15% |

判断优先级：

`历史价格结构 ≥ 成交量结构 > 均线趋势 > Fibonacci > ATR`

EMA8/13 交叉只用于调整均线趋势因子的内部评分，不作为独立交易信号。

## 三层价格结构

普通模式：

- **核心交易区**：参考位上下 `±0.25 ATR`
- **观察带**：参考位上下 `±0.25～0.40 ATR`
- **收盘失效线**：单独列示，不与观察带混写

当 `ATR / price > 8%` 时启用高波动趋势模式：

- 顺趋势区间收窄至 `±0.20 ATR`
- 逆趋势区间扩宽至 `±0.45 ATR`
- 偏弱市场中不输出积极左侧做多建议
- 盘中反弹必须等待收盘确认

## Johnny 关键位框架

内部计算完整候选地图，对每个候选检查以下共振：

1. 主波段 Fibonacci 回撤
2. 次级推动段 Fibonacci 扩展
3. 历史平台、前高前低或整数位
4. 趋势线或平行通道
5. EMA 簇或 Vegas 隧道
6. 成交量与价格行为
7. TD 九转或结构信号
8. 基准指数同向确认

评分解释：

- `5–8` 项：强关键位，可制定条件化交易计划
- `3–4` 项：中等关键位，轻仓并等待确认
- `1–2` 项：弱候选，不得单独作为入场依据

默认每侧只输出 2–3 个作用独立的关键位；证据不足时允许少于 2 个，不使用弱点凑数。

## 输出内容

融合模式下，每个标的通常包含：

1. 一句话结论与数据时间
2. 当前价、短线偏向、基准指数状态和 `ATR/price`
3. 每侧 2–3 个关键支撑位与压力位
4. 核心交易区、观察带和独立收盘失效线
5. `策略方向：左侧 / 右侧 / 观望`
6. 入场确认、失效条件、目标 1/2、仓位和收益风险比
7. 财报、流动性、跳空及数据缺口风险

## 数据与执行纪律

- 每次分析使用最新有效行情，不沿用上一交易日区间或历史静态点位
- 区分盘中触及、盘中站稳和收盘确认
- 不把 Fib、TD、EMA 交叉或单次触线作为独立信号
- 不预测精确底部，不把单日上涨直接定义为反转
- 技术支撑不能覆盖重大基本面恶化
- 所有路径均应写成条件情景，而非确定性预测

### 行情获取与异常处理

不限定行情工具或传输通道，可使用 Yahoo Chart API、`yfinance`、金融行情工具或其他可靠来源。执行时遵循：

1. 优先取得最新、完整、可复核的周线、日线和小时线 OHLCV 数据
2. 单一通道因 robots、网络、权限、限频或服务异常失败时，切换其他可靠通道
3. 记录数据源、获取时间、市场时区、币种和最后一根有效 K 线时间
4. 替代数据需检查时间窗、字段、复权、公司行动和最新价；关键价格冲突时用第二可靠来源核对
5. 只有在可用通道均无法满足数据完整性要求时才停止分析
6. 不使用过期缓存、推测数据或无 OHLCV 明细的网页摘要补位

## 特殊标的说明

- `DRAM` 按 **Roundhill Memory ETF** 识别，不是 Dataram
- `NBIS` 需要单独提示流动性与波动风险
- `COHR`、`WDC`、`NBIS`、`LITE` 应重点检查高波动模式，但最终以当日 `ATR/price` 为准
